# AIM:
To develop Library Management System using Star UML

# SRS (Procedure):
#### Step 1: Problem Identification
Identify the need for a system to manage books, library members, book issuing, returns, and fines efficiently.

#### Step 2: Requirement Analysis
Identify users such as Student, Faculty, Librarian and Admin. Define functional requirements like adding books, searching books, issuing books, returning books, and calculating fines.

#### Step 3: System Design
Create UML diagrams using StarUML, including Use Case, Class, Activity, and Sequence Diagrams. Design the database for book, member, and transaction details.
